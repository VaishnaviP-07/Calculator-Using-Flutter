# Flutter Calculator App

A simple and clean calculator app built with Flutter and Dart. It has a dark theme with orange operator buttons and a layout that adapts to different screen sizes.

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Clear button to reset the calculation
- Dark theme with rounded buttons
- Responsive layout that adjusts to screen width

## Technologies Used

- Flutter
- Dart

## How to Run

1. Install Flutter on your system
2. Clone this repository
   `git clone https://github.com/[your-username]/[your-repo-name].git`
3. Open the project folder
4. Run `flutter pub get`
5. Run `flutter run`

## Project Structure

- `lib/main.dart` : contains the complete calculator UI and logic
